# CoinGlass 加密方案情报（v=1 时代）

> 来源：Xeron2000/coinglass-decrypt（MIT，webpack module 12471 逆向）+ 实测。最后核验 2026-09。

## 1. 传输协议

```
GET https://capi.coinglass.com/api/<path>?<query>
```

### 必需请求头（加密端点）

```
encryption: true
cache-ts-v2: <当前时间戳 ms>          # 参与 v=0 密钥派生
language: en
Origin: https://www.coinglass.com
Referer: https://www.coinglass.com/
User-Agent: <Chrome 系完整 UA>
Accept: application/json, text/plain, */*
```

### 响应（加密端点）

```
HTTP 200
v: 1                    # 密钥版本（决定 Key0 派生方式）
user: <base64 token>    # 存有"真实 AES key"的密文 token
ev: 2                   # 载荷编码/压缩版本号
content-type: application/json

{"code":"0","msg":"success","data":"<base64 加密载荷>"}
```

不带 `v` / `user` 头的端点 = 明文端点，直接 `resp.json()`。

## 2. 解密算法（双层 AES-128-ECB + gzip）

```
响应头 user(base64) ──decode──▶ token 密文
响应头 v = 1 ──▶ Key0 = base64(url_path)[:16]     # url_path 含 /api/... 
Key0 解密 token ──▶ gzip 数据 ──gunzip──▶ 16 位 hex 真实 key
真实 key 解密 data(base64) ──▶ gzip 数据 ──gunzip──▶ 明文 JSON
```

伪代码：

```
key0   = b64encode(urlparse(url).path.encode()).decode()[:16]   # v=1
actual_key = gzip.decompress(aes_ecb_decrypt(token,  key0)).decode()
plain  = gzip.decompress(aes_ecb_decrypt(payload, actual_key)).decode()
json   = json.loads(plain)
```

注意：ECB 无 IV，两处密文都需 `unpad(…, 16)` 再去 gzip。

## 3. 密钥版本（v）派生表

CoinGlass webpack module 12471（函数 `Xt`）按日轮换密钥来源：

| v | Key0 = base64(…)[:16] | 备注 |
|---|---|---|
| 0 | 请求头 `cache-ts-v2` | 每日窗口期（如 08:00–10:00 UTC+8）出现 |
| **1** | **URL path** | **当前通用，136+ 端点全部 v=1** |
| 2 | 响应头 `time` | 备用 |
| 55 | `170b070da9654622` | 遗留常量，已不再返回 |
| 66 | `d6537d845a964081` | 遗留常量，已不再返回 |
| 77 | `863f08689c97435b` | 遗留常量，已不再返回 |

实现上应全量支持 0/1/2 + 遗留表，以应对轮换。
